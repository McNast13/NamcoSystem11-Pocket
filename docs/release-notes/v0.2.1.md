**What's new in v0.2.1**

- **Point Blank 2 and Gunbarl can be played.** Until now the guns were fixed at the centre of the screen, so the gun games
  could not be aimed. Each player now aims with the left stick or the d-pad (player 1 on pad 1, player 2 on pad 2) and fires
  with any face button.
  - The d-pad moves slowly for the first quarter of a second, for fine aim, then speeds up to full speed; the stick is
    proportional.
  - A MAME-style sight shows where each player is aiming: blue for player 1, red for player 2 once player 2 joins.
  - New setting **Gun aim speed** (Normal, Slow, Fast).
- **Point Blank 2 no longer freezes in the armour mini-game.** The picture stopped (with the sound still playing) about 10
  seconds into the "shoot the armour off" stage. The game resets the GPU's command buffer while playing, and the core's GPU,
  still busy drawing, was cut off mid-way. For the gun games that reset now only restarts the command framing, as in MAME and
  as the core already did for Tekken.

Tested on a Pocket: Point Blank 2 (`ptblank2a`) and Gunbarl (`gunbarla`), with one and two players, handheld and docked.
