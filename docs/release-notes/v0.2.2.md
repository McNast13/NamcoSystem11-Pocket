**What's new in v0.2.2**

- **Beta.** Every game in the list has now been tested as working on a Pocket, including Dunk Mania and Star Sweep, and the
  alternative versions of Tekken, Tekken 2 and Point Blank 2. Tekken 2's longer combos (King's 10-hit combo) work.
- **Game settings are saved.** Changes made in a game's test menu (difficulty, rounds, coinage and so on) are now kept: each
  game gets its own `.sav` under `Saves/namco_system11/` when you quit the core, and it is loaded the next time you open that
  game. After changing a setting, leave the test menu and wait a couple of seconds before quitting.
  - Earlier versions never wrote a save at all. The core did not tell the Pocket how big the save was.
- **Core settings work.** DIP1 Test, DIP2 Freeze, Service button (held) and Gun aim speed never took effect in earlier
  versions: the core read the setting values with their bytes in the wrong order. They now do.
  - **DIP1 Test** opens the game's test menu at start-up.
  - **Service button (held)** is the cabinet's service button: switching it on adds a service credit.
  - **DIP2 Freeze** is passed to the game; most games, Tekken 2 among them, ignore it.
- **Point Blank 2's test menu needs the Dock.** To change Point Blank 2's settings, use the Dock with two controllers
  connected, for player 1 and player 2: the game's test menu needs both players' controls.
- New fitter seed (44): the design changed, and seed 44 gives the best timing yet.

Tested on a Pocket: Tekken 2 settings kept across launches, DIP1 Test, Service button and Gun aim speed, and games loading
normally after quitting the core.
